A one-chat run after it landed. Real listing of a scratch run made with
`sh scripts/fleet.sh file / chips --agents / next / find / finish / drained / merge / render / landed`
on 2026-11-11 (two repo slots, two tasks, one finding). The shape of every file is in docs/PROTOCOL.md,
"Directory layout"; this is only what one small run leaves behind.
