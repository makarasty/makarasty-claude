Fix the pattern, not the page. When the person reports a visual or behaviour defect on one page, first find where it comes from: a shared component, style or helper used by other pages too. Fix it there once, so every page that uses it is fixed, and say which other pages changed. Never patch one page over a shared defect (an override, an inline style, a page-only class); the person then has to report the same defect again on the next page.
